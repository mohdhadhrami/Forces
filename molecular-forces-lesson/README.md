# قوى الترابط بين الجزيئات - درس تفاعلي

## 📚 نظرة عامة

صفحة ويب تعليمية تفاعلية شاملة لشرح درس "قوى الترابط بين الجزيئات" للصف الحادي عشر. تتضمن الصفحة نماذج ثلاثية الأبعاد تفاعلية، رسوم بيانية ديناميكية، واختبار تفاعلي شامل.

## ✨ الميزات

### 📖 المحتوى التعليمي
- **قوى فان دير فالس**: شرح مفصل لقوى لندن التشتتية وقوى ثنائي القطب
- **الرابطة الهيدروجينية**: الشروط، آلية التكوين، والأمثلة
- **الخصائص الفيزيائية**: تأثير القوى على درجات الغليان، الكثافة، والتوتر السطحي
- **السالبية الكهربائية**: شرح مفصل مع حاسبة تفاعلية

### 🎨 التصميم
- تصميم عصري وجذاب بألوان تعليمية احترافية
- متجاوب تماماً (Responsive) لجميع الأجهزة
- وضع ليلي/نهاري قابل للتبديل
- رسوم متحركة سلسة وجذابة

### 🔬 العناصر التفاعلية
- نماذج جزيئية ثلاثية الأبعاد قابلة للدوران
- رسوم بيانية تفاعلية للبيانات العلمية
- جداول قابلة للفرز والبحث
- حاسبة السالبية الكهربائية
- محاكي درجة الحرارة
- مختبر افتراضي لمقارنة الجزيئات

### 🎯 نظام التقدم
- تتبع التقدم في كل قسم
- نظام نقاط وإنجازات
- حفظ تلقائي للتقدم في المتصفح
- اختبار تفاعلي شامل مع 10 أسئلة

## 🛠️ التقنيات المستخدمة

- **HTML5**: بنية دلالية حديثة
- **CSS3**: تصميم متقدم مع Grid و Flexbox
- **JavaScript**: تفاعلية كاملة بدون مكتبات خارجية للمنطق الأساسي
- **Three.js**: نماذج ثلاثية الأبعاد (placeholder)
- **Chart.js**: رسوم بيانية تفاعلية
- **AOS**: رسوم متحركة عند التمرير
- **Font Awesome**: أيقونات جميلة
- **Google Fonts (Cairo)**: خط عربي واضح

## 🚀 كيفية الاستخدام

1. **فتح الملف**: افتح `index.html` في أي متصفح حديث
2. **التنقل**: استخدم القائمة الجانبية للانتقال بين الأقسام
3. **التفاعل**: انقر على العناصر التفاعلية للحصول على معلومات إضافية
4. **الاختبار**: أكمل جميع الأقسام ثم جرب الاختبار النهائي

## 📊 المحتوى العلمي

### قوى الترابط المغطاة:
- قوى لندن التشتتية (0.05-40 kJ/mol)
- قوى ثنائي القطب الدائم (2-10 kJ/mol)
- الروابط الهيدروجينية (10-40 kJ/mol)

### الجزيئات المدروسة:
- **المجموعة 15**: NH₃, PH₃, AsH₃
- **المجموعة 16**: H₂O, H₂S, H₂Se, H₂Te
- **الهاليدات**: HF, HCl, HBr, HI

### البيانات المتضمنة:
- درجات الغليان لجميع الجزيئات
- قيم السالبية الكهربائية
- طاقات الروابط
- خصائص فيزيائية متنوعة
